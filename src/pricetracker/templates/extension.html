Browser add-on

Read flyers on the stores' websites in Firefox (or Chrome) and send them here with one click, no phone app needed.

1 · Install it

Download the add-on (.zip)

Firefox (140 or newer): unzip it, open about:debugging#/runtime/this-firefox, click Load Temporary Add-on… and pick manifest.json from the unzipped folder. Firefox removes temporary add-ons when it restarts. To keep it, see “Keep it installed” below.

Chrome, Edge, Brave: unzip it, open chrome://extensions, turn on Developer mode, click Load unpacked and pick the folder.

Then pin the € button to the toolbar.

3 · Use it

PDF flyers

On a flyer page with a “Descargar”/“Descarregar” button or a PDF link (Consum, Dia, Aldi, Ahorramás, Plusfresc…), the add-on lists the PDFs. Click Send PDF. On Lidl's online viewer it finds the leaflet's PDF for you. A PDF already open in Firefox can be sent with Send this tab's address.

Online viewers

Viewers load one large image per page. Flip through every page, then click Add page images: thumbnails, logos and duplicate copies are skipped. Press Read now when done.

Offer pages with prices as text

Pages that list products and prices (Carrefour's campaign pages, Aldi's offers page, online-shop promotion lists) can be sent as text with Send page text. Scroll to the bottom first so everything has loaded. Text is cheaper for Claude to read than images and prices are copied exactly.

Anything else: screenshots

Add visible area works on any page. Show a page, add it, move on, add the next one, then Read now. Firefox can also capture the whole scrolling page in one go.

Keep it installed (Firefox)

Release versions of Firefox only keep add-ons that Mozilla has signed. Signing your own copy is free and automatic, and it is not published anywhere (an “unlisted” add-on):

  1. Create API credentials at addons.mozilla.org/developers/addon/api/key/ (any Firefox account works).
  2. Run, in the unzipped add-on folder: npx web-ext sign --channel=unlisted --api-key=… --api-secret=…
  3. Open the signed .xpi it produces with Firefox. Signing is automatic and usually takes minutes (up to a day if Mozilla picks it for a manual check).

Firefox Developer Edition, Nightly and ESR can instead install it unsigned once xpinstall.signatures.required is set to false in about:config.

What gets sent where

The add-on only talks to this app, at the address above (keep it 127.0.0.1 or localhost). When you send something, the app downloads the PDF or images itself (only from public internet addresses, never from your home network) and passes the pages, or the page text, to Claude to read the prices. That is why Firefox lists “website content” and “browsing activity” when you install it. It never sends anything on its own: only when you click a button in its popup.
